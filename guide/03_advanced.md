# 03. 운영·성능·보안

## 1. 운영 아키텍처

권장 경계는 업로드 계층, 전처리 워커, GPU 추론 서버, 후처리·검증 계층, 결과 저장소입니다. 공개 인터넷에서 GPU 서버의 포트 10000을 직접 노출하지 말고 인증·요청 제한·감사를 제공하는 API 게이트웨이 뒤에 둡니다.

```text
클라이언트 → 인증/크기 제한 → PDF 검사·페이지화 → GPU 추론
         → 구조 검증·민감정보 정책 → 암호화 저장/응답
```

## 2. 성능 튜닝

### 메모리

SGLang 예시는 `--mem-fraction-static 0.8`, context length 32768, page size 1을 사용합니다. 긴 생성은 KV cache를 크게 사용하므로 다음 순서로 접근하세요.

1. 실제 출력 길이 분포를 측정합니다.
2. 불필요하게 큰 context length를 줄일 수 있는지 검토합니다.
3. 동시성별 peak VRAM을 기록합니다.
4. OOM 시 요청 큐, 페이지 분할, 별도 GPU pool을 적용합니다.

### 처리량

파일 크기순 정렬은 큰 작업을 먼저 시작해 전체 완료 시간을 줄일 수 있지만 작은 요청의 대기시간을 늘릴 수 있습니다. 대화형 요청과 배치 요청은 별도 큐로 분리하고 SLA에 맞는 스케줄링을 사용하세요.

### 이미지 전처리

무조건 300 DPI가 최선은 아닙니다. 150/200/300 DPI에 대해 정확도와 렌더링·추론 비용을 비교하고, 작은 글자나 도면만 고해상도로 올리는 정책을 실험하세요.

## 3. 보안 체크리스트

- 업로드 파일의 확장자가 아니라 실제 시그니처와 MIME을 검사합니다.
- 최대 파일 크기, 픽셀 수, PDF 페이지 수, 압축 해제 크기를 제한합니다.
- PDF JavaScript·첨부 파일 등 능동 콘텐츠를 신뢰하지 않습니다.
- 모델의 remote code revision과 컨테이너 digest를 고정합니다.
- Base64 원문과 OCR 결과를 일반 로그에 남기지 않습니다.
- 임시 이미지와 결과에 만료·삭제 정책을 적용합니다.
- 프롬프트 인젝션이 포함된 문서라도 후속 도구 호출 권한을 얻지 못하게 합니다.
- OCR 결과를 HTML로 표시할 때 escape/sanitize합니다.

## 4. 신뢰성과 장애 대응

현재 `infer.py`는 실패한 요청도 최종 집계 후 프로세스를 오류 코드로 종료하지 않습니다. 자동화 파이프라인에서는 성공률을 파싱하거나 래퍼에서 실패 목록을 수집해 기준 미달 시 실패 처리하세요.

관측 항목:

- 서버 준비 시간과 모델 로드 실패 원인
- 요청별 status code, 시도 횟수, 첫 토큰·완료 시간
- 입력 페이지 수·픽셀 수와 출력 길이
- GPU 사용률, VRAM, OOM·재시작 수
- 빈 출력, 잘린 출력, 반복 출력 비율

결과 파일명은 상대 경로의 구분자를 `__`로 바꾸므로 서로 다른 경로가 같은 이름으로 충돌할 가능성을 검토해야 합니다. 운영에서는 작업 ID와 입력 해시를 포함시키는 편이 안전합니다.

## 5. 품질 게이트

고위험 문서에는 다음 단계를 적용합니다.

1. 스키마 또는 Markdown 문법 검증
2. 필수 필드·페이지 수 누락 검사
3. 합계와 부분합 같은 산술 일관성 검사
4. 낮은 신뢰도 또는 비정상 길이 탐지
5. 원본 좌표를 보여 주는 사람 검수 UI

생성형 OCR은 그럴듯한 문자를 만들 수 있으므로, 원본에 없는 값이 결과에 나타나는 환각을 별도 오류 유형으로 추적해야 합니다.

## 6. 확장 방향

- 문서 유형별 프롬프트와 출력 스키마
- 페이지 단위 재시도·체크포인트와 중단 재개
- 중복 파일을 건너뛰는 콘텐츠 해시 캐시
- 다중 GPU 큐와 backpressure
- 한국어 문서 전용 평가 세트와 회귀 테스트
- 결과의 표·수식·읽기 순서 정규화

## 7. 테스트와 기여

이 저장소는 기여 코드가 PEP 8을 따르고 적절한 위치에 배치되며 단위 테스트를 포함할 것을 요구합니다. 변경 시 최소한 다음을 검증하세요.

```bash
python -m py_compile infer.py guide/examples/build_sglang_request.py
python guide/examples/build_sglang_request.py assets/baidu.png --summary-only
git diff --check
```

GPU 통합 테스트는 별도로 Transformers 또는 SGLang 경로의 대표 이미지와 PDF를 실행하고, 결과를 승인된 기준 출력과 비교합니다.
